## 1. Overview of Changes

In accordance with `DISPATCH.md` and the recommendations of `auditor_m1_iter2`, `explorer_m1_iter3_1`, `explorer_m1_iter3_2`, and `explorer_m1_iter3_3`, all four forensic audit remediation deliverables have been fully implemented:

   - Replaced non-memoizing `checkCleanTheorems` with `MemoAxioms.collect` (cycle-safe, memoized kernel axiom traversal matching `tests/PhaseAxiomCensus.lean`).

2. **`tools/build_accepted_proofs_dataset.py`**:
   - Implemented `mask_comments_and_strings`: masks strings, line comments, block comments, and docstrings while preserving character offsets and newlines.
   - Implemented `find_declaration_assignment`: lexical scanner identifying top-level assignment delimiter `:=` strictly at bracket-depth 0 across `()`, `[]`, `{}`, `⟨⟩`, and `⦃⦄`. Never splits inside parameter binders like `(M := M)`.
   - Implemented `clean_proof_trailing`: backward scanner stripping trailing comments, docstrings, section dividers, and whitespace.
   - Implemented `is_substantive_proof`: strictly rejects empty proofs, `"by"`, syntax fragments like `"M)"`, and proofs starting with closing delimiters.
   - Added `DIRTY_CONSTANTS`: set of 54 `sorryAx`-dependent constants in `GromovCompactness`. Skips any test declaration referencing dirty constants.
   - Replaced `slice_source_proof`: depth-0 assignment splitting eliminates all 47 library syntax corruptions where signatures were split on `(M := M)`.
   - Replaced `harvest_test_proofs`: uses command boundaries, depth-0 assignment splitting, strict `sorry`/`admit` chunk checks, `DIRTY_CONSTANTS` filtering, and truthful `"axioms": None` attestation.
   - Removed all occurrences of hardcoded axiom lists `["propext", "Classical.choice", "Quot.sound"]`. Library records dynamically pull `"axioms"` from the Lean kernel output.

3. **`data/raw_accepted_theorems.jsonl`**:
   - Regenerated with 748 clean theorem records, each containing genuine kernel axiom arrays.

4. **`data/gemma_accepted_proofs.jsonl`**:
   - Regenerated with 908 genuine zero-`sorry` proof pairs (395 library + 513 test).
