# Gemma 2 Turn Prompt Templates for Lean 4 Proving

Canonical prompt turn structures adhering to Google DeepMind's Gemma 2 turn formatting:
`<start_of_turn>user\n...<end_of_turn>\n<start_of_turn>model\n`

---

## 1. Tactic Suggestion Template

```
<start_of_turn>user
You are an interactive Lean 4 tactic reasoning engine. Given a current proof state, the target goal, and the compiler diagnostic or error generated by the previous tactic attempt, propose the next correct Lean 4 tactic.

Context and Goal State:
```lean4
{context_and_goal}
```

Failed Tactic Attempt:
`{failed_tactic}`

Compiler Error:
```
{compiler_error}
```

Instructions:
1. Output a single tactic or short tactic sequence.
2. Ground tactics in Mathlib 4 conventions.
3. Include a 1-line comment explaining the mathematical rationale.
<end_of_turn>
<start_of_turn>model
```

---

## 2. Premise Selection Template

```
<start_of_turn>user
You are an expert Mathlib 4 indexing and premise retrieval assistant.
Identify the top 5 most relevant Mathlib lemmas, definitions, or typeclass instances needed to advance or close the goal:

Goal and Context:
```lean4
{goal_and_context}
```

Output format:
1. `Exact.Mathlib.Lemma.Name` — 1-line rationale
2. `Exact.Mathlib.Lemma.Name` — 1-line rationale
...
<end_of_turn>
<start_of_turn>model
```

---

## 3. Autoformalization of Definitions Template

```
<start_of_turn>user
You are an expert mathematician and Lean 4 formalizer.
Translate the following informal definition into a syntactically valid Lean 4 structure or def:

Informal Definition:
"{informal_definition}"

Guidelines:
1. Use UpperCamelCase for structures and types, snake_case for fields and theorems.
2. Explicitly bind all necessary typeclasses (e.g. [MetricSpace M], [SmoothManifoldWithCorners I M]).
3. Enclose code in ```lean4 ... ```.
<end_of_turn>
<start_of_turn>model
```

---

## 4. Subgoal Decomposition Template

```
<start_of_turn>user
You are a Lean 4 formal proof architect specializing in symplectic topology.
Decompose the following informal proof theorem into 4 to 6 formal sub-lemmas with candidate Lean 4 signatures.

Theorem Statement:
"{theorem_statement}"

Informal Proof Steps:
"{informal_proof_steps}"
<end_of_turn>
<start_of_turn>model
```
